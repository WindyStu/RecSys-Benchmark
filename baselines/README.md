# Baseline Source Trees

This directory contains sanitized copies of local baseline implementations.

The benchmark code in `recsys_benchmark/` is MIT licensed. Third-party or paper
code under this directory may have different licenses or missing license
metadata. Before publishing a release, run the open-source checklist in
`docs/open_source_checklist.md` and add proper attribution for each method.

Do not commit datasets, checkpoints, logs, pretrained weights, embeddings, API
keys, or local IDE/cache files here.
